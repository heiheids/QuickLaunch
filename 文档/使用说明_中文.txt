QuickLaunch 快速启动器  v1.0.4  使用说明（中文）
================================================================

一、这是什么
----------------------------------------------------------------
一个 Windows 桌面快捷启动面板。纯 Rust + Win32/GDI+ 手写，单文件绿色运行，
零第三方依赖，不写注册表（只在你主动开启“开机启动”时才建快捷方式）。

二、启动与呼出
----------------------------------------------------------------
1. 双击 QuickLaunch.exe 即可运行，程序驻留系统托盘。
2. 默认全局呼出快捷键：Ctrl + Alt + Q（可在设置里改成任意组合）。
3. 左键单击 / 双击托盘图标也能呼出；关闭窗口 = 隐藏到托盘。
4. 托盘右键菜单里可以“退出”，退出时会自动保存所有数据。

三、添加项目
----------------------------------------------------------------
方式一：从桌面 / 资源管理器把文件、文件夹、快捷方式直接“拖”进窗口。
方式二：窗口空白处右键，选择“添加程序或文件” / “添加文件夹”。
方式三：右键菜单“添加网址”。

★ 本版重点：拖进来的“快捷方式”（.lnk）会被自动解析成它指向的源程序。
  例如把桌面上“记事本 - 快捷方式”拖进来，程序里记录的是
  C:\Windows\system32\notepad.exe，之后你把桌面上那个图标删掉，
  程序里的条目照样能启动。网址快捷方式（.url）同样会被解析成真实网址。

  旧版本遗留的、指向 .lnk 的条目，在快捷方式文件仍然存在时，
  会在下次启动时自动修正为真实目标（只改路径，不改名字）。

四、日常操作
----------------------------------------------------------------
· 单击图标 = 启动；右键图标 = 菜单（打开位置 / 属性 / 重命名 / 移动 / 删除 等）
· 右键“以管理员身份运行”= 以管理员权限启动
· 按住图标拖动超过 5 像素 = 调整顺序，松手自动保存
· 右键“属性”= 打开该条目对应快捷方式的属性窗口（快捷方式已被删除时显示目标程序属性）
· 顶部搜索框 = 按名称 / 路径 / 备注实时过滤
· Ctrl / Shift + 单击 = 多选，可批量运行或删除
· 分组栏右键 = 新建 / 重命名 / 删除分组，上下移动

五、设置
----------------------------------------------------------------
标题栏“设置”按钮里可以调整：图标大小（小/中/大）、视图（磁贴/列表）、
窗口置顶、窗口阴影、不透明度、字体大小、显示日期、主色（自动派生整套配色）、
呼出快捷键、开机启动。

六、数据放在哪里
----------------------------------------------------------------
全部在 exe 同目录下，删掉即彻底卸载：
  conf.ini          窗口位置、大小、配色、快捷键等设置
  db\links.txt      分组 / 标签 / 链接数据（Tab 分隔文本，可直接编辑）
  cache\icons\      图标缓存，可随时删除，程序会重新生成

七、常见问题
----------------------------------------------------------------
Q: 拖进去的图标名字带“ - 快捷方式”后缀？
A: 名字取的是快捷方式文件名（和你桌面上看到的一致），可以在右键菜单里重命名。

Q: 右键“属性”为什么显示的是快捷方式的属性？
A: 条目本身连的是目标程序，但程序额外记下了你拖进来的那个快捷方式，
   所以属性窗口打开的是快捷方式本身；快捷方式被删掉后会自动改为显示程序属性。

Q: 指向应用商店应用（UWP）的快捷方式没被解析？
A: 那类快捷方式没有普通文件路径，程序会按原样保留，功能不受影响。

Q: 换了电脑 / 移动了程序目录？
A: 整个文件夹一起复制即可，数据都是相对路径，不需要重新配置。

Q: 杀毒软件报警？
A: 程序无签名、体积小、会调用 ShellExecute 启动别的程序，属于常见误报，
   可加入信任列表后使用。

八、分组栏宽度调整（v1.0.8）
----------------------------------------------------------------
分组栏和右边的快捷方式之间有一条竖线，鼠标移上去会变成左右箭头：
  · 左右拖动即可改变分组栏宽度，松手后自动保存，下次启动保持。
  · 往左拖到底，分组栏最窄只剩一个字的宽度（内容区自动让出空间）。
  · 往右拖到底，内容区仍会保留至少 120 像素，不会被挤没。
  · 分割线有 ±3 像素的容错带，不必精确点在那一像素上。
